Built with React, TypeScript, and Tailwind CSS, this portfolio showcases Milan's projects, research, skills, internships, and more with beautiful, responsive design and smooth animations.

## ⚡ Getting Started

### 1. **Clone the repository**
```bash
git clone https://github.com/milansinghal2004/portfolio.git
cd portfolio
```

### 2. **Install dependencies**
```bash
npm install
```

### 3. **Run the development server**
```bash
npm run dev
```
Visit [http://localhost:5173](http://localhost:5173) to view your portfolio.

### 4. **Build for production**
```bash
npm run build
```

## 📝 Customization
- **Edit your data:**
  - `src/data/projects.ts` — Projects
  - `src/data/skills.tsx` — Skills (grouped by category)
  - `src/data/internships.ts` — Internships/Experience
  - `src/data/publications.ts` — Research/Publications
  - `src/data/socialLinks.ts` — Social media links
- **Change images:** Place your images in the `public/` or `src/assets/` folder and update the paths in your data files.
- **Update sections:** Edit or reorder sections in `src/App.tsx`.
- **Colors & Theme:** Adjust Tailwind colors in `tailwind.config.js`.
